## Standard description (≈ 700 characters)

```
Founded, designed and built OpenSpot League (openspotleague.com) on my own, a web platform for skateboard, BMX, scooter and roller riders. Built an interactive spot map with geospatial search, a contest system with live and video judging scored by a rating engine based on the World Skate criteria, and real-time multiplayer trick games. Stack: Next.js 16, React 19, TypeScript, PostgreSQL/PostGIS, Supabase, Drizzle ORM, Cloudflare Workers and R2, with email notifications on AWS (Lambda, SQS, SES). Applied a layered architecture, server-side caching, role-based access control and automated testing (~270 test files). Currently live in pre-launch, ahead of a public release.
```
